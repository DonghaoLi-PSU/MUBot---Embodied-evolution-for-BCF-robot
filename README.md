# MUBot---Embodied-evolution-for-BCF-robot
MUBot Evolution is an embodied morphology-learning framework for modular body-caudal-fin (BCF) swimming robots. Built on the experimentally grounded μBot platform and its analytical hydrodynamic simulation model, this project co-evolves body-plan variables — segment count, body dimensions, joint stiffness, joint angle ranges, and caudal-fin type — with controller optimization via parameter-exploring policy gradients (PGPE). Across a population of 400+ evaluated morphologies, the framework maps how evolution reshapes morphology and reward distributions, identifies which design variables govern peak swimming performance, and compares morphologies optimized for absolute speed versus body-lengths-per-second. The goal is a population-level design map for BCF swimmers and a computational route toward more principled aquatic robot design.
